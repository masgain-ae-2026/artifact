## 1. 적합성 판정 민감도

### 1.1 계산 조건·검증

| 항목 | 값 |
|---|---|
| 검정 | exact two-sided McNemar; doubled lower exact binomial tail |
| 유의수준 | `alpha = 0.05` |
| 효과 | paired risk difference `delta` |
| 불일치율 | discordance rate `d` |
| 실제 단위 수 | `n = 8, 15, 50` |
| 목표 검정력 | `0.8, 0.9` |
| 실제 단위 수 계산 | 원본 `exact_power` 직접 호출 75회 |
| 최소 요구 `n` 탐색 | 동일 rejection rule의 조건부 exact decomposition; 정수 `n=1`부터 순서대로 열거 |
| 직접/조건부 일치 점검 | 75개 실제 단위 조합 전부; 최대 절대차 `8.237227986760520165810499187E-16` |
| 공개 검증기 자체 실행 | exit code `0`; `status = PASS` |
| 기준 조합 공개 검증기 결과 | `delta=0.2`, `d=0.5`, `n=102`: `0.7976421823155178`; `n=103`: `0.8018189073387402` |
| 경계 원본함수 대조 | 50개 최소-n 경계 각각 `n-1`, `n`: 원본 `exact_power` 직접 호출 100회; 50/50 모두 `power(n-1) < target <= power(n)` 확인 |

조건부 분해식:

```text
M ~ Binomial(n, d)
favored | M=m ~ Binomial(m, q), q=(d+|delta|)/(2d)
reject iff 2 * BinomialLowerTail(min(favored, opposing); m, 0.5) <= alpha
power = sum_m P(M=m) * P(reject | M=m)
```

원본 함수 호출 형태:

```python
exact_power(
    task_count=n,
    paired_risk_difference=Decimal(delta),
    discordance_rate=Decimal(d),
    two_sided_alpha=Decimal("0.05"),
)
```

원본 `artifact/audit/independent_power_enum.py` 편집: 없음; 호출 전·후 SHA-256 동일.
